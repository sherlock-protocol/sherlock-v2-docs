# Overview

Qualifying customers can run a bug bounty program on Sherlock.&#x20;

Security researchers submit vulnerabilities on the program's page on Sherlock's website. The protocol team reviews reports, comments on them and approves verdicts on the Sherlock bug bounty dashboard. Sherlock sends each team member their own invite.&#x20;

Programs reserve the right to pause submissions at any time.&#x20;

**How reports are judged**&#x20;

Sherlock triages every report first. We check it against the program rules, the in-scope code, earlier submissions and known issues, then post a proposed verdict for the protocol team. In some cases an expert triager from Sherlock's community of security researchers triages the report instead. The protocol team reviews the verdict and approves it or pushes back. The protocol team has the final say on validity and severity. Sherlock then sends the final verdict to the researcher.&#x20;

Customers are also given access to Sherlock's full arbitration suite that includes access to the Sherlock Protocol Claim Committee and the UMA Optimistic Oracle to help with dispute resolution. Customers are provided with co-marketing of the customer's Bug Bounty Program according to Sherlock's standard marketing efforts.&#x20;
